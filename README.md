# Remedy Spa

Sales demo landing page for Remedy Spa, 35 Hai Bà Trưng, Quận 1, Ho Chi Minh City. English at `/en`, Vietnamese at `/vi`. `/` follows the browser `Accept-Language` header.

The booking form is a demo. It does not send a request.

```bash
npm install
npm run dev
```

`npm run build`, `npm run lint`, and `npm run typecheck` are the checks for this repo.

Open `/en?demo=confirmed` or `/vi?demo=confirmed` to see the confirmed screen. `/en?slots=error` shows the slot-load error state. Placeholders and unconfirmed WhatsApp/Zalo details are marked `TODO` in the source and listed on the pull request.
